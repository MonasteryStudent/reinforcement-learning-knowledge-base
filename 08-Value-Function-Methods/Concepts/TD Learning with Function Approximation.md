## Definition

**TD learning with function approximation** combines [[Temporal-Difference Learning]] with [[Value Function Approximation]] to estimate the state values of a given [[Policy]].

Instead of storing and updating a separate value for every state, the algorithm represents the estimated state-value function as

$$
\hat{v}(s,\mathbf{w}),
$$

where $\mathbf{w}$ is a parameter vector. Each observed transition is used to update $\mathbf{w}_t$ so that the estimate $\hat{v}(s_t,\mathbf{w}_t)$ moves closer to the one-step TD target.

Because the same parameters may influence the values of multiple states, an update based on one transition can also change the estimated values of states that were not visited.

The algorithm performs policy evaluation: it estimates the state values of a fixed policy but does not improve the policy.

## Mathematical Formulation

For a given policy $\pi$, the approximation objective is

$$
J(\mathbf{w})
=
\mathbb{E}
\left[
\left(
v_\pi(S)-\hat{v}(S,\mathbf{w})
\right)^2
\right].
$$

The distribution of $S$, commonly the [[Stationary Distribution]] under policy $\pi$, determines how the errors of the individual states are weighted.

A stochastic-gradient update using the true state value would be

$$
\mathbf{w}_{t+1}
=
\mathbf{w}_t
+
\alpha_t
\left[
v_\pi(s_t)-\hat{v}(s_t,\mathbf{w}_t)
\right]
\nabla_{\mathbf{w}}
\hat{v}(s_t,\mathbf{w}_t).
$$

Because the true value $v_\pi(s_t)$ is unknown, it is replaced by the one-step [[TD Target and TD Error|TD target]]

$$
r_{t+1}
+
\gamma\hat{v}(s_{t+1},\mathbf{w}_t).
$$

The resulting parameter update is

$$
\mathbf{w}_{t+1}
=
\mathbf{w}_t
+
\alpha_t
\left[
r_{t+1}
+
\gamma\hat{v}(s_{t+1},\mathbf{w}_t)
-
\hat{v}(s_t,\mathbf{w}_t)
\right]
\nabla_{\mathbf{w}}
\hat{v}(s_t,\mathbf{w}_t).
$$

For [[Linear Function Approximation]], where

$$
\hat{v}(s,\mathbf{w})
=
\boldsymbol{\phi}^{T}(s)\mathbf{w},
$$

the gradient is

$$
\nabla_{\mathbf{w}}\hat{v}(s,\mathbf{w})
=
\boldsymbol{\phi}(s).
$$

The update therefore becomes

$$
\mathbf{w}_{t+1}
=
\mathbf{w}_t
+
\alpha_t
\left[
r_{t+1}
+
\gamma\boldsymbol{\phi}^{T}(s_{t+1})\mathbf{w}_t
-
\boldsymbol{\phi}^{T}(s_t)\mathbf{w}_t
\right]
\boldsymbol{\phi}(s_t).
$$

## Algorithm

Initialize a differentiable function $\hat{v}(s,\mathbf{w})$ and a parameter vector $\mathbf{w}_0$.

For every episode generated by policy $\pi$:

1. Observe a transition $(s_t,r_{t+1},s_{t+1})$.
2. Update the parameter vector:

   $$
   \mathbf{w}_{t+1}
   =
   \mathbf{w}_t
   +
   \alpha_t
   \left[
   r_{t+1}
   +
   \gamma\hat{v}(s_{t+1},\mathbf{w}_t)
   -
   \hat{v}(s_t,\mathbf{w}_t)
   \right]
   \nabla_{\mathbf{w}}
   \hat{v}(s_t,\mathbf{w}_t).
   $$
