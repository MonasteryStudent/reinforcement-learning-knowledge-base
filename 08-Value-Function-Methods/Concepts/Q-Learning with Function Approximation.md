## Definition

**Q-learning with function approximation** extends [[Q-Learning]] by representing the action-value function with a parameterized function

$$
\hat{q}(s,a,\mathbf{w})
$$

instead of storing a separate value for every state-action pair.

Unlike [[Sarsa with Function Approximation]], Q-learning does not use the action that is actually selected in the next state to construct its TD target. Instead, it uses the greatest approximated action value available in the next state.

The algorithm therefore approximates the optimal action values associated with the [[Bellman Optimality Equation]]. Because multiple action-value estimates can depend on the same parameters, updating $\mathbf{w}_t$ for one state-action pair may also change the estimates of other state-action pairs.

Q-learning with function approximation can be implemented in either an [[On-Policy and Off-Policy Learning|on-policy or off-policy]] manner. The action-value update is the same in both cases; the difference concerns how the experience samples are generated.

## Mathematical Formulation

The optimal action value is approximated by

$$
q^*(s,a)
\approx
\hat{q}(s,a,\mathbf{w}).
$$

The Q-learning [[TD Target and TD Error|TD target]] is

$$
r_{t+1}
+
\gamma
\max_{a\in\mathcal{A}(s_{t+1})}
\hat{q}(s_{t+1},a,\mathbf{w}_t).
$$

The parameter update is

$$
\mathbf{w}_{t+1}
=
\mathbf{w}_t
+
\alpha_t
\left[
r_{t+1}
+
\gamma
\max_{a\in\mathcal{A}(s_{t+1})}
\hat{q}(s_{t+1},a,\mathbf{w}_t)
-
\hat{q}(s_t,a_t,\mathbf{w}_t)
\right]
\nabla_{\mathbf{w}}
\hat{q}(s_t,a_t,\mathbf{w}_t).
$$

For [[Linear Function Approximation]], the action-value estimate is

$$
\hat{q}(s,a,\mathbf{w})
=
\boldsymbol{\phi}^{T}(s,a)\mathbf{w},
$$

and its gradient is

$$
\nabla_{\mathbf{w}}
\hat{q}(s,a,\mathbf{w})
=
\boldsymbol{\phi}(s,a).
$$

The parameter update therefore becomes

$$
\mathbf{w}_{t+1}
=
\mathbf{w}_t
+
\alpha_t
\left[
r_{t+1}
+
\gamma
\max_{a\in\mathcal{A}(s_{t+1})}
\boldsymbol{\phi}^{T}(s_{t+1},a)\mathbf{w}_t
-
\boldsymbol{\phi}^{T}(s_t,a_t)\mathbf{w}_t
\right]
\boldsymbol{\phi}(s_t,a_t).
$$

After the parameter update, a greedy action for the current state is

$$
a^*
=
\underset{a\in\mathcal{A}(s_t)}
{\arg\max}
\ \hat{q}(s_t,a,\mathbf{w}_{t+1}).
$$

For an on-policy implementation, the policy for the current state can be updated according to

$$
\pi_{t+1}(a\mid s_t)
=
\begin{cases}
1-\varepsilon+\dfrac{\varepsilon}{|\mathcal{A}(s_t)|},
& a=a^*,\\
\dfrac{\varepsilon}{|\mathcal{A}(s_t)|},
& a\neq a^*.
\end{cases}
$$

## Algorithm

Initialize the parameter vector $\mathbf{w}_0$ and an initial policy $\pi_0$.

For every episode:

1. Start in the initial state $s_0$.
2. For every transition until the target state is reached:

   - Select $a_t$ according to the current policy.
   - Execute $a_t$ and observe $r_{t+1}$ and $s_{t+1}$.
   - Calculate the Q-learning target:

     $$
     \bar{q}_t
     =
     r_{t+1}
     +
     \gamma
     \max_{a\in\mathcal{A}(s_{t+1})}
     \hat{q}(s_{t+1},a,\mathbf{w}_t).
     $$

   - Calculate the TD error:

     $$
     \delta_t
     =
     \hat{q}(s_t,a_t,\mathbf{w}_t)
     -
     \bar{q}_t.
     $$

   - Update the parameter vector:

     $$
     \mathbf{w}_{t+1}
     =
     \mathbf{w}_t
     +
     \alpha_t
     \left[
     r_{t+1}
     +
     \gamma
     \max_{a\in\mathcal{A}(s_{t+1})}
     \hat{q}(s_{t+1},a,\mathbf{w}_t)
     -
     \hat{q}(s_t,a_t,\mathbf{w}_t)
     \right]
     \nabla_{\mathbf{w}}
     \hat{q}(s_t,a_t,\mathbf{w}_t).
     $$

   - Make the policy for $s_t$ $\varepsilon$-greedy with respect to $\hat{q}(s_t,a,\mathbf{w}_{t+1})$.
   - Continue with $s_{t+1}$.

In an off-policy implementation, the experience samples may instead be generated by a separate behavior policy. The Q-learning target still uses the greatest approximated action value in the next state.

The action values are represented by a function, but the policy is still represented as a table in the on-policy version described above. It therefore requires finite state and action spaces for its policy representation.
