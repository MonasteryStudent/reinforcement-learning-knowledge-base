## Definition

**Online learning** means that an agent updates its value estimates or policy while interacting with the environment. New experience is generated and processed during the learning process.

**Offline learning** means that learning is performed using previously collected experience. The agent does not interact with the environment while the algorithm processes this data.

The distinction between online and offline learning concerns **when and how the experience is obtained**. It is therefore different from the distinction between [[On-Policy and Off-Policy Learning]], which concerns the relationship between the behavior policy and target policy.

## Mathematical Formulation

In online learning, the agent generates a transition

$$
(s_t,a_t,r_{t+1},s_{t+1})
$$

through interaction with the environment and uses it to perform an update. A general temporal-difference update can be written as

$$
q_{t+1}(s_t,a_t)
=
q_t(s_t,a_t)
-
\alpha_t(s_t,a_t)
\left[
q_t(s_t,a_t)-\bar{q}_t
\right].
$$

The updated action values can influence the agent's subsequent behavior and therefore the experience generated during later time steps.

In offline learning, the transitions are taken from a previously collected dataset

$$
\mathcal{D}
=
\left\{
(s_i,a_i,r_{i+1},s_{i+1})
\right\}_{i=1}^{N}.
$$

The learning algorithm processes the transitions in $\mathcal{D}$ without generating new experience through interaction with the environment.

## Comparison

| Property | Online learning | Offline learning |
|---|---|---|
| Source of experience | Current interaction with the environment | Previously collected dataset |
| Interaction during learning | Yes | No |
| Updates | Performed while experience is generated | Performed using stored experience |
| Influence on future data | The learned policy can affect subsequently generated experience | The dataset remains fixed |

## Relationship to On-Policy and Off-Policy Learning

An on-policy algorithm such as [[Sarsa]] learns from experience generated by the policy currently being improved. It is therefore naturally used for online learning.

An off-policy algorithm such as [[Q-Learning]] can be used both online and offline:

- In **online off-policy learning**, the agent generates new experience using a behavior policy while learning about a different target policy.
- In **offline off-policy learning**, the algorithm learns from previously collected experience that may have been generated by another policy.

Therefore, **on-policy versus off-policy** describes which policies generate and use the experience, whereas **online versus offline** describes whether the experience is generated during learning or was collected beforehand.
